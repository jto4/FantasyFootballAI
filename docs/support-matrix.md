# Support matrix

This matrix describes what the current source implements and what has actually been
verified. A passing fixture or packaged smoke check does not mean a live provider account
or every supported operating system has been validated. Last reviewed: 2026-09-28 (hosted run 36375960956 completed successfully; native macOS LaunchAgent lifecycle and credential-store round trip passed locally; the current Apple Silicon DMG passed packaged API/dashboard, MCP, and headless API health/clean-shutdown smokes plus `hdiutil verify`; its update ZIP was rebuilt from the same source and both hashes were refreshed on 2026-09-28; the current DMG SHA-256 is `0a4fa1155e8801eb548d36ea0fd6a926e647d7e33b422e1c2f94e404838f1e09`; the local unsigned package also generated a darwin-arm64 updater ZIP; an isolated packaged macOS GUI check verified first-run rendering, close-to-tray with the API still listening, and tray Quit with a clean API shutdown; the five configured news feeds returned 10 parseable headlines each on a live check at 10:40 UTC; league disconnection confirmation/error handling, duplicate/ambiguous report-send safeguards, and API backup/league router extractions are included; shared dashboard loading/error states, backup image refresh, provider connection-status failures, state validation, credential refresh handling, raw-page recovery, and live news feed checks are recorded below).

The full repository test suite passed on the declared Node.js 22.13.0 minimum after rebuilding
the native `better-sqlite3` binding for that runtime. Typecheck, lint, formatting, and production
build passed on Node.js 25.9.0. Windows- and Linux-specific runtime checks still rely on the
hosted CI and owner-device verification recorded below.

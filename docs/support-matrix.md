# Support matrix

This matrix describes what the current source implements and what has actually been
verified. A passing fixture or packaged smoke check does not mean a live provider account
or every supported operating system has been validated. Last reviewed: 2026-09-28 05:51 UTC (hosted run 36375960956 completed successfully; native macOS LaunchAgent lifecycle and credential-store round trip passed locally; the Apple Silicon DMG was rebuilt with packaged API/dashboard and MCP smoke checks and passed `hdiutil verify`).
